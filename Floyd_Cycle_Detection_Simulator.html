Floyd's Cycle Detection Algorithm — Interactive Simulator

Build a singly linked list of any size, optionally wire its tail back into itself to create a cycle, then step through Floyd's two-pointer algorithm (a slow pointer P1 and a fast pointer P2) to detect the cycle and locate exactly where it begins. Every step is animated on the diagram, logged on the right, and mapped onto the pseudocode being executed.

1 · Define the linked list

Nodes are numbered 0 to N−1 in list order. Set which node the last node's next pointer connects back to, in order to create a cycle — or use −1 for a plain list with no cycle.
